# Google Play listing: everything to paste into the Play Console

Package: `es.jrg.objectdetection`. Privacy policy: https://jgomezsa.github.io/android_ObjectDetection/privacy.html

The app is called **Detecta** (launcher label: `app_name` in `app/src/main/res/values/strings.xml`). The Play *title* is set in the Console and may add the words people search for, so
the app is found both by name and by "object detection". Keep it descriptive, not a list of keywords (Play's metadata policy rejects keyword stuffing).

## Store listing (English, default language)

**App name / title** (max 30 characters): Detecta: Object Detection

(Alternatives if you prefer: "Detecta - Object Detector", "Detecta: AI Object Detection".)

**Short description** (max 80): Real-time object detection with your camera, on your phone. No cloud.

**Full description** (max 4000):

Detecta is a real-time object detection app: point your camera at the world and see what it recognises, live, with a box and a name around each object. Everything runs on your phone: nothing is uploaded, no account is needed, and there are no ads.

- Real-time detection of 80 everyday kinds of objects: people, vehicles, animals, furniture, food and more.
- Uses your phone's GPU when it can, and falls back to the CPU when it cannot.
- Two built-in models: YOLOX-S (more accurate) and YOLOX-Tiny (faster). Switch from the model name at the top right.
- Confidence slider: choose how sure the model must be before a box is shown.
- Uses the camera's real zoom levels, including the ultrawide lens on phones that allow it: tap a point, slide, or pinch.
- Frame-time graph, so you can see how fast your phone is.
- Record a video with the detection boxes drawn on it; it is saved to your Movies folder.
- Add your own models: type the address of a model file (TFLite or ONNX, for example a model trained to find potholes or license plates), give it a name, and the app downloads it, checks it and adds it to the list. Supports YOLOX, YOLOv8/YOLO11, NMS-free YOLO and DETR-style detectors.

Private by design: camera images are processed on the device and never leave it. The internet is used only when you download a model you chose.

The source code is published on GitHub for reading and noncommercial use under the PolyForm Noncommercial License 1.0.0. It is not an open-source licence: commercial use is not allowed without permission. The built-in models are YOLOX (Apache License 2.0). Models you download yourself have their own licences.
